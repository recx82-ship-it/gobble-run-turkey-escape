Gobble Run — The Great Turkey Escape is an original 2D turkey escape game. Thanksgiving is coming, and Giblet the turkey has to sprint 1500 metres across the farmyard to the freedom woods while Farmer Bram chases him from behind, the oven already hot and the carving knife out. Switch between three lanes, jump the carving knives and hay bales, go around the ovens (they cannot be jumped), and grab corn and pumpkin pie on the way. Every stumble costs a life and lets the farmer close in — if he catches up, it is Thanksgiving dinner. A title screen, a live HUD (score, distance to the woods, lives and a farmer-distance bar), caught and escaped end screens with restart, pause and mute, and WebAudio-synthesised gobbles, jumps, pickups and fanfares — no audio files. It plays offline in a desktop browser from static files, with no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
